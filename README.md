# 🚀 3D Developer Portfolio Website

Portfolio website pribadi yang dibangun menggunakan React, TypeScript,
Three.js, GSAP, dan WebGL.

Website ini merupakan portfolio pribadi yang telah dikustomisasi dengan
informasi, project, foto, dan video milik saya.

## 👀 Preview

[![Portfolio Preview](Screenshot%202026-09-10%20140619.png)](vidio.mp4)

## ✨ Features

- 3D / WebGL experience menggunakan Three.js
- Smooth animations dengan GSAP
- React + TypeScript
- Responsive untuk desktop dan mobile
- Personal portfolio dan project showcase
- Interactive 3D experience

## 🧰 Tech Stack

- React
- TypeScript
- Three.js / WebGL
- GSAP
- HTML
- CSS
- JavaScript
- Vite
